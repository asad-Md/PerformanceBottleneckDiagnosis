# Realtime Bottleneck Diagnosis Dashboard

This frontend is a static dashboard for the realtime ML inference pipeline in [src/realtime](../realtime).

## Scope

- The dashboard is intentionally isolated under [src/frontend](.).
- It does not modify or run the Linux-only backend under [src/realtime](../realtime).
- It reads from a small integration adapter that can be swapped with the real data source later.

## Current data mode

The UI currently uses mock sample data through the adapter layer so it can be designed and visually validated without running the Linux backend.

## Integration contract

The actual realtime pipeline exposes:

- A snapshot reader that reconstructs one row per `(pid, cpu)` via pinned BPF maps.
- Feature engineering derived from scheduling, memory, syscall, and lock counters.
- Prediction output with `pid`, `cpu`, `comm`, `pred_class`, `prediction`, `is_bottleneck`, and `confidence`.

The adapter layer is structured to accept data shaped like the output of `RealtimeReader.predict()` and the predictor payload in [src/realtime/predictor.py](../realtime/predictor.py).

## Recommended future connection

On the Linux host, connect the adapter to:

1. the realtime predictor output stream,
2. a REST or websocket endpoint if one is exposed externally,
3. or a polling JSON export generated by the Linux service.

The UI is designed to accept that data without changing the backend implementation.
